# DoDA Wiki

Welcome to the official DoDA technical documentation.

## What is DoDA?
DoDA is a mod for GZDoom that implements advanced custom weapon systems, mission management, and complex character mechanics, including deadzone aiming and tactical leaning.

## Authority
This wiki is generated and maintained from the current active source code (`gzdoda/doda-core/`).
1. Explicit human instructions are the primary authority.
2. `AGENTS.md` and active `zscript.txt` include order define source and build rules.
3. Current active source files are the authoritative implementation documentation.
4. Local `ZDoom_Documentation/` is the authority for ZScript and engine API semantics.

**Note:** Runtime validation is human-performed using SLADE and GZDoom. This wiki contains static analysis of the source.
